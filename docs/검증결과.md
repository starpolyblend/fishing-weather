# v0.1.0 검증 결과

## 완료

- Node.js 자동 테스트 10개 통과: 한국 시간 자정·연도 변경, 발표 지연·이전 발표 선택, 위경도 격자 변환 기준점, 0과 결측값 구분, 강수량 구간 보존, 인증키 인코딩, CORS 출처 제한, 격자 제한, 인증키 미설정, API 페이지 처리, 이전 발표 재시도, 인증 오류 메시지 정제.
- 브라우저에서 초기 미연결 상태, 예시 표시, 오늘/내일 전환, 장소 변경 후 날짜 유지, 수문 미연결 상태를 확인.
- 360px·412px 너비의 브라우저 프레임에서 상단 제목·장소·날짜 버튼 배치를 확인.
- 설정 화면에서 좌표 누락 시 파일 생성 대신 오류를 표시하는 것을 확인.

## 아직 확인하지 않은 항목

- 사용자 인증키를 이용한 기상청 실응답 및 실제 Cloudflare 배포.
- 실제 낚시 포인트의 좌표. 두 장소 모두 설정 필요.
- Android 실기기 설치·실사용. 브라우저 프레임 검사는 실기기 검사를 대체하지 않음.
- 수문정보 API: 관측소 미지정으로 미구현. 현재 준비 안내와 공식 사이트 링크만 제공.

API 테스트의 응답은 테스트 파일에만 있으며 실제 서비스 화면으로 연결되지 않습니다. 화면용 예시 데이터는 ?demo=1에서만 표시됩니다.
